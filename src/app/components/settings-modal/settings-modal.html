Backfill precious-metal data

Fills in Metal Content, Composition, PM % and PM Weight (g) for coins that are missing them, working the values out from each coin's country, denomination and year — the same inference the Quicken import uses. Melt value is calculated from PM Weight and Metal Content, so coins added before that inference existed show no melt figure until this is run.

It only ever fills blanks: anything you have already entered is left exactly as it is. Coins whose alloy cannot be determined from the date alone — a 1942 nickel, a 1982 cent, a 1971-78 Eisenhower dollar — are skipped rather than guessed at, because a wrong purity would silently produce a wrong melt value.
