Batch Import Images

Change this to your photo folder. It starts out showing where this app is installed — a real folder on the host, but almost certainly not where your coin pictures are. It is only there to give you the right drive and the right starting shape to edit, for example D:\Coin Pictures. Whatever you set is remembered, so you only do this once.

The folder is stored with each photo so you can click through to the original full-size file later. The server opens that file, not your browser — so the path has to be valid on the machine hosting the app, written the way that machine sees it: a local drive letter. A drive mapped only on your own PC, or a network path the host cannot reach, will store fine and then report every photo as missing.
