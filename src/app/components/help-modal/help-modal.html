Help

The buttons along the top

Add Coin
Puts a blank row in the grid for you to fill in.
Import
Reads coins out of a spreadsheet (Excel or CSV) or a Quicken QIF file. The same menu's Images from folder works the other way round: it reads a folder of photographs and matches them to coins you already have.
Export
Writes your inventory out as CSV, as JSON for a backup, or as an insurance CSV.
Settings
Where your folders, display options and reference lists are set up.

Something not working?

Write down what happened and this saves a report to your Desktop that you can send on. Your user name, folder paths and anything that looks private are replaced before the file is written, and nothing is uploaded.
